# Mineral Focus 1.0.0

Created by **Arthur**.

Mineral Focus 1.0.0 establishes the project's visual system and public project structure for COSMIC Epoch 1.9.x.

Highlights:
- graphite-first dark theme;
- matching light companion;
- mineral-mint focus accent;
- restrained Frosted Glass;
- opaque application content windows;
- COSMIC-native spacing and tiling-gap behavior;
- documented ThemeBuilder v2 compatibility;
- permanent creator attribution and contributor tracking;
- release, test, publishing, and maintenance rules.
