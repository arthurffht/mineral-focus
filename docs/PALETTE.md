## Accent rule

Mint is intentionally scarce. Use it for focus, selection, active controls, progress, and primary actions. Large decorative accent surfaces are outside the project's visual language.

## Glass rule

Dark uses `Medium2` with an alpha-map value of `0.81` at the selected level.

Light uses `Medium2` with an alpha-map value of `0.865` at the selected level.

Normal and maximized application windows remain opaque by default.
