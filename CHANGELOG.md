# Changelog

All notable public changes to Mineral Focus should be recorded here.

## 1.0.0 — 2026-09-26

Initial public release prepared for COSMIC Epoch 1.9.x.

### Added
- Mineral Focus dark theme
- Mineral Focus Light companion
- graphite neutral ramps
- mineral-mint focus accent
- dedicated semantic success, warning, and destructive colors
- Frosted Glass configuration for system interface, panel, and applets
- opaque normal/maximized content windows
- `3 px` active-window hint
- full project documentation, authorship, contribution, validation, and publishing structure

### Compatibility
- targets `libcosmic` ThemeBuilder v2
- uses current default tiling gaps `(0, 8)`
